# Logo Placeholder

Para adicionar a logo da sua empresa, coloque o arquivo `logo.png` neste diretório.

O arquivo será servido em: `http://localhost:3000/config/assets/logo.png`

## Recomendações:
- Formato: PNG ou SVG
- Tamanho recomendado: 32x32 pixels para favicon
- Para logo principal: até 200x200 pixels
- Qualidade: Alta resolução para displays retina

## Exemplo de comando para copiar sua logo:
```bash
cp /caminho/para/sua/logo.png config/assets/logo.png
```
